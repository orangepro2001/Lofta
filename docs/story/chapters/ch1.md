# 第一章 周报（章节脚本）

主问题：南是怎么死的？新动词：演绎、查验形式。没有新的历法知识，九月只作笑话和章末样张出现。

## 日期和时段预算

1752 年 8 月 1 日星期六至 8 月 4 日星期二，旧式。预算 12 时段，每天 3 格，星期二夜里交账。

花时段的场景共 14 个，预算 12，所以这一章确实看不完。开场旁白明说，见 `ch1_open`。

必需线：`c1_not_drunk` 不花时段（闻南的嘴即可）。查到砒霜最短 3 时段（基恩太太、读书或皮姆、试铁），占预算 25%，不超过 60% 的上限。本章没有不可逆限时事件。

时段的花法：地图走动、闲聊、搜查免费。花时段的都是选项，文字写“（花一个时段）”。每次 `~ time 1` 都同时 `~ add ch1_spent 1`，花时段的选项都带 `var:ch1_spent<12`，所以同一个菜单里也不可能超支。

## 分支和后果

**选择一：周报写什么。**

| 选项 | 条件 | 本章后果 | 后续 |
| --- | --- | --- | --- |
| “饮酒过量”，收两个格罗特 | 无 | 多八便士，鲍尔松一口气 | `ch1_took_groat`：第三章约翰少答一题，第六章当庭揭穿 |
| “发现已死” | 无 | 不收钱，皮姆说也好 | `ch1_found_dead`，第二章玛德莱娜不主动上门 |
| “中毒” | 有 `c1_not_drunk` 或 `c1_arsenic` | 进黑马对质 | 成立得 `ch1_bill_true`；不成立转 `ch1_found_dead`，羊皮纸写“蒙上帝召唤” |

**选择二：诬告基恩太太。** 只在对质第二轮，手上有谬误卡 `c1_keane_did` 时出现。警役带走她关一夜。第二天放了，铺盖已经被扔到街上。章末跳蚤解开欠账的那个结，消息不收钱，转身走。第二章他不来，第四章爱尔兰渡工不帮忙。

**选择三：南的先令。** 她拆开衣边时拿到先令。南说过要用它买一块新布，别让她光着进坑。

| 去向 | 后果 |
| --- | --- |
| 给基恩太太（可以先收起来，回头再给）| 基恩太太信她，说出自己五月喝过一勺补药。对质时她站出来作证，抵消一次错误。章末她在缝那块布 |
| 交给皮姆 | 记账抵葬费。南裹教区旧麻布 |
| 星期一拿去付房租 | 房租清了，找回三便士。基恩太太看见拆开的衣边，从此不抬头，守夜的选项消失，对质时不站出来 |
| 留在手上 | 章末她走得比平时快 |

守夜（花一个时段）是取得基恩太太信任的第二条路，先令和时段二选一即可。

**小选择：十一日站哪边。** 替鞋匠说话，星期一菲普斯太太话说得冷；替房东说话，她放宽到星期三；问“那十一天里死的人怎么算”，两边都不得罪。只改变别人怎么看她。

**对质规则。** 三轮。同一轮出错牌，验尸官反驳并缩小方向，这一轮重来，错牌消失。认输（“说不上来”）算一错，进入下一轮。容错 2 次，到 3 次不成立。第二轮没有出示砒霜也不成立，因为羊皮纸不能写没有人说过的东西。基恩太太站出来时错误减一。

`ch1_blamed_keane` 成立的玩家手上一定有 `c1_arsenic`，因为 `c1_keane_did` 由它合成，所以这一轮还能接着出示真牌。诬告后第三轮再引基恩太太的证词，验尸官会当场驳回，多记一错。

## 轻场景

连续两个沉重场景之间至少一个轻场景。

- 跳蚤的蠢事：想尝砒霜（`ch1_iron_done`）；闻活人挨了多兰一拳（`ch1_flea_menu`）；把“死人”拖了三趟，卖了他的鞋（`ch1_boundary_done`）。
- “十一日”轻事件：霍奇用粉笔算米迦勒节房租（`ch1_eleven_first`），之后每次路过门板上的数都在长（`ch1_eleven_again`）。多兰的轿租、书贩的十九天日历、皮姆的账本是它的余波。
- 将军的腿：每问一次丢在不同的地方。
- 皮姆的茶、拉德大妈的草褥账、克兰的脉。

沉重场景：南的尸体、守夜、穷人坑、对质、章末。场景由玩家排序，强制场景已经错开。
